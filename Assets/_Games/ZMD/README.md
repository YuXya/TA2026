## 继续学习的边界

- 已确认：Ramp Alpha 是有效控制数据；环境颜色与强度被分开处理；主光高光有摄像机偏置；暗部 LUT 属于材质颜色映射。
- 必须区分：资源存在、某次绘制绑定、某分支实际启用。事件 1154 没有绑定暗部 LUT，不能给所有身体材质默认加 LUT。
- 已解码的新参数可能选择固定环境色分支。不能把 HSV 环境处理说成该帧每个材质一定走的路径。
- 优先延续普通身体材质讨论。脸部 SDF、眼睛视差此前明确暂不展开，头发和其他特殊层可以后续再学。
- 可以先用可控灯光和环境建立学习基线，但须说明与原始运行时资源的差异。完整 GI 体积和实时阴影缓冲并未齐备，不能承诺只套贴图就逐像素一致。
- 后续教学默认从 Unlit 起步；不要未经用户说明，一次替他完成全部渲染管线或照搬旧工程所有效果。
