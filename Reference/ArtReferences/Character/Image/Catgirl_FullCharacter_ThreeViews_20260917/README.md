# 完整人物三视图

依据原完整 A-pose、身体修正版 v4、侧面及背面头发 v3，用内置 image_gen 同时生成完整人物正面、左侧面（朝画面左方）和背面，加入项圈与颈部铃铛。

- full_character_three_views.png：三视图合图，1672 × 941。
- full_character_front.png：正面，580 × 941。
- full_character_left.png：左侧面，380 × 941。
- full_character_back.png：背面，580 × 941。

三张单图直接从合图裁切，不重新生成、不缩放，共用原图的垂直对齐和像素比例。保留白色背景，无文字标签。

生成要求保留衣服后部中央尾巴开口、尾巴与蝴蝶结前后遮挡、鞋头和鞋跟区别，以及后脑长发和猫耳外侧。二维生成参考仍可能存在局部投影差异，三维建模时需统一。

用于整体图生模型与现有分部件模型进行对照。完整提示词、参考路径及裁切范围见 prompts.json。
