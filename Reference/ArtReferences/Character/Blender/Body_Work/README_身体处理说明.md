# 角色 A：身体 UV、贴图转移与基础绑定 v01

当前场景 `角色A.blend` 已保存；另有 `角色A_身体UV整理_v01.blend` 与 `角色A_身体绑定_v01.blend` 两个阶段文件。

## 已完成

- 仅处理 `猫猫身体`。头部网格和 UV 经哈希比较，与用户的 `猫猫头部备份` 一致，头部已恢复显示，未添加父级或修改器。
- 保留用户备份、隐藏的 `身体_UV原始参考`、原 UV、原材质和原图。工作身体使用独立 `Body_Material`。
- 移除 2 个游离顶点，拆开 11 条连接超过两面的异常边；不改变表面位置，不做全身重拓扑，不封闭正常衣服开口。当前身体 15,976 顶点、17,467 面。
- 新增 `Body_UV`：单张 0–1 图集，从原来 2,099 岛整理为 346 岛；衣身、袖子、手脚、尾巴等主要面片已合并。饰品及局部复杂褶皱仍保留小岛，其中 150 岛少于 5 面。
- UV 三角形相交检查未发现有效面积的重叠。使用 4K 下 16 像素打包间距和 8 像素烘焙扩边；提供棋盘格检查图及 UV 布局 PNG/SVG。
- 原材质实际只有一张 2K 底色图；已从原 UV 转移为 `Body_BaseColor_4K.png`，并打包进 blend。没有凭空增加法线、粗糙度贴图，也没有生成新的纹理细节。
- 使用无灯光底色烘焙；正、侧、背同机位渲染比较平均绝对色差均低于 1 个 8-bit 色阶。原图已有的阴影和错误图案仍保留。
- 新建 `BodyRig`：52 根骨骼，含根骨、躯干、肩臂、双手手指、腿脚与预留的颈/头骨。基础 FK 绑定，无 IK 控制器。
- 自动热权重实际解算失败，因此改用身体分区、衣服表面连通关系与手指表面距离分配，并经过姿势修正。无漏权重点；权重归一化；每个顶点最多 4 个骨骼影响。
- 尾巴、蝴蝶结与尾铃整体跟随 Hips。头部对象不绑定；本轮不制作摆动物理，不修改 Unity。

## 在 Blender 中检查

打开身体绑定版本，选择 `BodyRig`，时间轴已有动作 `BodyRig_动作检查`。默认停在第 1 帧，保持原 A-pose。

| 帧 | 检查内容 |
| --- | --- |
| 1、120 | 原 A-pose |
| 20 | 双臂抬起 |
| 40 | 双肘弯曲 95° |
| 60 | 左腿抬起 40°、膝盖弯曲 85° |
| 80 | 弯腰 20°、转体 20° |
| 100 | 手指弯曲 / 握拳检查 |

头部暂未绑定，检查躯干动作时请隐藏 `猫猫头部`，避免静止头发遮住身体。恢复第 1 帧后再显示头部。原模型朝向 +X，角色左侧为 +Y；未做 Unity 导出和 Humanoid 映射验证。

## 仍需注意

- 深度握拳的指节仍比较粗，拇指尚未调整成自然的包握姿势；适合作为初版绑定检查，手部近景动画仍需局部拓扑、权重及姿势精修。
- 大幅度抬腿时，衣摆与短裤仅靠骨骼权重变形，没有布料碰撞或修正形态键；不能视为任意动作都不会穿插。
- 背面原贴图的暗块及错误细节、AI 生成的原始造型瑕疵不会因为重排 UV 自动消失。
- UV 阶段文件保存时头部临时隐藏；最终绑定文件已恢复。
