## UV 与材质

头部仍是一个网格对象，使用独立 `Head_Material`、`Head_UV` 和 `Head_BaseColor_4K.png`。4K 图片已外部保存并打包进 blend。原 2K 底色通过原 UV 采样、Emission 烘焙转移，没有新增灯光，也没有新增法线或粗糙度贴图。4K 不代表补出了原图没有的细节。

原始 UV 为 2191 岛；拆开异常网格连接后，原 UV 坐标不变，连通计数为 2248；新 UV 为 587 岛。复杂卷发、耳内毛和细小饰品仍有小岛，没有为减少数量而强行拼接。面部、耳内外、主要发束、呆毛与发饰已按区域展开，区域存于面属性 `Head_Part`；对象的 `Head_Part_Names` 保存编号对应名称。

UV 三角形相交检测无面积大于 1e-10 的重叠，未发现有面积的模型三角形在 UV 中塌缩。最终实测最小岛间距约 32 像素，烘焙扩边为 8 像素。UV 坐标均位于 0–1。

文件：`Head_BaseColor_4K.png`、`Head_UV_Layout.png`、`Head_UV_Layout.svg`、`UV_before_after.png`、`UV棋盘格检查.png`、`外观前后对照.png`。

- 为展开与独立变形拆开了 121 条多面共享的异常边，顶点数由 11045 增为 11327，面数仍为 12155。没有移动原表面、全局合并或自动重拓扑。
- 按每个面的顶点位置与备份比较：静止表面位置误差为 0；原 UV 坐标误差为 0。
- 身体网格、权重和 UV 的 SHA-256 与本轮开始前一致；原 52 根骨骼的头尾位置和父级一致。原身体动作已在 1、20、40、60、80、100、120 帧复查，见 `身体动作复查.png`。
- 转头、俯仰、猫耳、呆毛和主发束测试均未带动脸部变形。浮点计算下脸部相对 Head 的最大误差约 4.4e-7 个场景单位。
- 同机位无光照贴图比较，正、侧、背及脸部近景平均 RGB 误差均低于 1/255。原图自带明暗、AI 模型原有的内侧贴色和局部造型缺陷仍保留；贴图重排没有重建这些内容。
- 头发仍是 FK 骨骼蒙皮，未设置与脸、肩膀、衣物的碰撞。转头、低头及身体抬臂时，靠肩长发存在穿插风险；当前检查姿态不能保证所有组合姿态无穿插。后续应通过手动摆发、碰撞或动态解算处理。刘海/卷发边界仍受原始 AI 网格布线限制，大幅弯折应继续局部修权重或修拓扑。
- 未制作眼球控制、嘴型、表情、摆动物理，也未进行 Unity 导入验收。
